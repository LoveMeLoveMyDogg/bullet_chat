# BulletChat API-Key 测试指南

本指南用于你拿到自己的 API Key 后，对 BulletChat 做最终验收。分「快速验收」和「完整验收」两档，按顺序做即可。

## 准备

1. 启动软件：`npm start`（托盘出现图标）
2. 右键托盘 → 打开设置

---

## 一、文字模型（文件弹幕）——快速验收

1. **填配置**：接口地址 / API Key / 模型名（默认已填 DeepSeek 官方地址和 `deepseek-chat`）
   - DeepSeek：`https://api.deepseek.com` + `deepseek-chat`
   - opencode-go 中转：填它的地址 + 你买的模型名（支持视觉的那个也可用于下方视觉测试）
2. **点「测试连接」**：应显示绿色 ✓ 和模型回复（比如「通」）
3. **保存** → 在桌面新建一个文件夹 → 屏幕上应飘出 AI 生成的搞笑弹幕（无【本地】前缀）
4. 试试：新建文件、删除文件、改名 → 各有对应吐槽

## 二、视觉模型（屏幕弹幕）——快速验收

1. 设置 → 视觉模型 → 勾选「启用屏幕识别」→ 填地址 / Key / 模型名 → 截图间隔默认 4 秒
2. **点「测试连接」**：应显示「✓ 视觉能力正常」（软件会发一张红色方块图，模型答对颜色才算过）
3. 保存（首次启用会弹隐私提示：截图仅发送给你配置的视觉 API 地址）
4. 打开浏览器随便操作 → 几秒后应飘出与屏幕内容相关的弹幕
5. **隐私遮罩验证**：设置 → 监控 → 隐私遮罩 → 选显示器 → 在预览图上拖一个框盖住屏幕一角 → 保存 → 再操作屏幕 → 视觉弹幕不应再"看见"被遮住的内容（可用"描述屏幕"类操作验证）

## 三、错误处理验收（重点，共 6 项）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 把文字 API Key 改错 → 保存 → 在桌面建文件夹 | 系统通知「文字模型出错：鉴权失败…」；设置页状态条变红；文字弹幕停止 |
| 2 | Key 改回正确 → 保存 | 立即恢复通知；再建文件夹 → 弹幕回来 |
| 3 | 只把视觉 Key 改错 → 保存 → 操作屏幕 | **只有屏幕弹幕停**；文字弹幕照常（按通道隔离） |
| 4 | 视觉 Key 改回正确 → 保存 | 屏幕弹幕恢复 |
| 5 | 断网 → 操作文件 | 通知「网络错误」；弹幕暂停；恢复网络后 60 秒内自动恢复并通知 |
| 6 | 不改 key，等 60 秒 | 无操作时弹幕静止（限速 10 秒/条在正常工作） |

## 四、托盘与配套验收

- 托盘「暂停弹幕」→ 文件操作无弹幕；「继续弹幕」→ 恢复
- 托盘「暂停屏幕识别」→ 屏幕操作无视觉弹幕（文件弹幕不受影响）
- 托盘「本地模式」勾选 → 弹幕变【本地】前缀模板弹，**不消耗 API 额度**
- 托盘「演示模式」→ 每 4 秒自动弹一条模拟事件弹幕（不用操作电脑也能看效果）
- 设置 → 系统 → 开机自启 → 勾选保存 → 重启电脑后软件自动后台运行

## 五、弹幕设置调优

- **最小间隔**：默认 10 秒/条。觉得吵调大（如 30），想密集调小（0 = 不限速，慎用）
- **风格池**：逗号分隔，比如 `阴阳怪气、捧场、脑补剧情`，模型会优先按这些画风弹
- **动画**：取消勾选后弹幕只显示文字不飘

## 六、离线自测（没有 key 也能试全流程）

用内置 mock 服务器模拟 OpenAI 兼容接口：

```bash
# 终端 1：启动 mock（默认正常模式）
node tools/mock-api-server.js 3999

# 终端 2：把测试配置写入（指向 mock；会备份你现有配置）
node tools/write-test-config.js
npm start
```

然后按第一节操作（测试连接会返回「通」、弹幕会返回 mock 的固定文案）。故障模式模拟：

```bash
MOCK_MODE=401  node tools/mock-api-server.js 3999   # 鉴权失败
MOCK_MODE=flaky node tools/mock-api-server.js 3999   # 前 2 次失败后成功（测自动恢复）
MOCK_MODE=delay node tools/mock-api-server.js 3999   # 35 秒无响应（测超时）
MOCK_MODE=html  node tools/mock-api-server.js 3999   # 返回非 JSON（测友好报错）
```

**测完恢复**：`node tools/write-test-config.js` 会备份原配置到 `config.json.bak-test`，测完手动恢复或删除测试配置即可。

## 七、已知问题（验收时留意，非 bug）

- **虚拟显示器**：ToDesk 等虚拟显示器上弹幕窗口可能不显示画面（Chromium 环境怪癖，物理屏正常）
- **"改来改去"弹幕偏多**：系统后台进程持续写文件时会触发修改类弹幕，如嫌吵可在设置把最小间隔调大，或后续版本提供"忽略修改事件"开关
- **锁屏时**：屏幕识别捕捉到的是锁屏画面，解锁后恢复正常
