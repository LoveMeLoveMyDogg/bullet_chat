# BulletChat（桌面弹幕直播）设计文档

日期：2026-08-05
状态：已获用户确认

## 1. 项目概述

一个 Windows 桌面趣味软件：像"直播观众"一样监控用户的操作，以弹幕形式在屏幕上飘过吐槽。

- **文件级监控**：监控所有盘符的文件系统事件（新建/删除/改名/移动/写入），任何程序的文件操作都会被"看见"
- **屏幕级识别**：定时截屏，画面发生变化时调用视觉模型识别屏幕内容并生成弹幕——捕捉纯 UI 操作（点按钮、切窗口、看视频等）
- **弹幕演出**：弹幕以 B 站风格在屏幕上方飘过（全屏置顶、鼠标穿透、不抢焦点），支持多显示器
- **内容生成**：弹幕由外部 LLM API 生成（OpenAI 兼容），用户自备 API Key；API 不可用时本地模板兜底，保证弹幕不冷场

目标用户：喜欢整活的个人用户。软件定位是自用趣味工具，不做商业化。

## 2. 技术栈

- **Electron**（Windows 平台），Node 22+，纯 JavaScript，无前端框架
- 文件监控：`fs.watch(path, { recursive: true })`——Windows 上底层为 ReadDirectoryChangesW，每盘符一个句柄即可监控整棵树
- 屏幕截图：`desktopCapturer`
- API 客户端：直接 `fetch` 调用 OpenAI 兼容的 `/chat/completions` 接口，不引入 SDK
- 测试：Node 内置 `node:test`
- 平台限定：v1 只支持 Windows（fs.watch recursive 依赖 Win 实现，代码按 Windows 设计）

## 3. 架构总览

三大模块 + 两个事件源：

```
文件事件源 FileWatcher ──┐
                         ├─→ 统一事件队列 → 弹幕大脑 Brain → 演出层 Stage
屏幕事件源 ScreenWatcher ─┘                                （每显示器一个弹幕窗口）
```

- **监控器（FileWatcher）**：所有盘符递归监控，事件进队列
- **屏幕事件源（ScreenWatcher）**：定时截屏 + 本地像素差异检测 + 视觉模型，变化才调 API
- **弹幕大脑（Brain）**：降噪 → 攒批 → 限速 → 生成（文字 API / 视觉 API / 本地模板兜底）
- **演出层（Stage）**：每个显示器一个透明置顶、鼠标穿透的弹幕窗口，CSS 动画飘弹幕

采集与显示彻底分离：监控再吵不影响弹幕流畅度，弹幕再花哨不卡监控。

## 4. 组件详情

### 4.1 文件事件源（FileWatcher）

- 启动时枚举固定盘符（C:、D:…），每个盘符根目录挂一个递归 `fs.watch`
- 事件类型：新建（文件/文件夹）、删除、改名、移动、写入
- 事件统一进队列，附带：类型、路径、文件名、盘符
- 监控句柄意外失效时自动重新挂载
- 盘符列表可在设置中勾选（默认全选）

### 4.2 屏幕事件源（ScreenWatcher）

- 定时截屏（默认每 4 秒，可调；支持多屏，默认主屏）
- **像素差异检测**：与上一帧比对（缩小后对比），画面变化率低于阈值则跳过，不调 API
- 画面变化时：截当前画面 → 应用隐私遮罩（涂黑）→ 发送给视觉模型 → 弹幕进统一队列
- 未配置视觉模型：提示用户"视觉模型未配置，屏幕弹幕未启用"，文件弹幕照常；视觉 API 失败按 §5 处理
- 托盘可单独暂停屏幕识别
- **隐私**：首次开启时明确提示"截图仅发送给你配置的视觉 API 地址"；支持设置隐私遮罩区域（矩形，发送前涂黑）

### 4.3 弹幕大脑（Brain）

**降噪过滤**（优先级高，防止刷屏）：
- 忽略系统噪音路径：`$Recycle.Bin`、`System Volume Information`、`Windows\`（更新目录）、`AppData\`（浏览器/微信缓存）、`node_modules`、`.git`、`__pycache__`、临时目录、`Thumbs.db`/`desktop.ini`
- 忽略高频小写入：同一文件的连续写入事件合并
- 事件洪峰时随机采样，保证弹幕质量优先
- 过滤规则可在设置中编辑

**攒批**：事件在队列中攒批（每 5 秒或攒够 10 条触发一次），一次调用生成 1~3 条弹幕——省 token、有"连击感"

**限速**：默认最小间隔 10 秒/条（可调），队列塞爆时丢最旧事件

**生成器（按事件源分路，无自动降级）**：
- 文件事件 → 文字 API（把一批事件的描述，如"用户新建了文件夹「新建文件夹」在桌面"，发给文字模型，返回 1~3 条弹幕）
- 屏幕事件 → 视觉 API（把变化后的截图发给视觉模型，返回 1~2 条弹幕）
- **出错即提示，不降级**：任一路 API 失败 → 立即停止该路生成并向用户明确提示（见 §5），绝不静默用模板顶替
- **本地模式（手动开关）**：设置中可手动开启，开启后弹幕由本地模板生成（按事件类型各内置 20+ 条多风格模板），所有弹幕带「【本地】」标记；仅限用户主动开启，永不自动触发
- 弹幕要求：强制 ≤20 字，短才像真弹幕

**风格池**：内置 10+ 种画风（阴阳怪气、捧场、脑补剧情、抽象梗、温柔提醒、专业吐槽、玩梗、古风、中英混搭、正经夸夸…），每次生成随机挑选几种写入提示词并明确要求"换着花样来"；用户示例（"新建了文件夹不改名字吗"、"又新建在c盘"）作为 few-shot 示例喂给模型；风格池在设置中可增删

### 4.4 演出层（Stage）

- 启动时枚举所有显示器，每个显示器一个透明、置顶、鼠标穿透（`setIgnoreMouseEvents(true, {forward: true})`）、不抢焦点的无边框窗口
- 监听显示器热插拔/分辨率变化，自动创建/销毁/重定位窗口
- 动画池：默认右→左横飘，随机混入顶部掉落、弹出放大、抖动摇摆；随机颜色、字号、偶尔 emoji
- 多条弹幕自动分道（多行轨道）避免重叠，同屏最多 N 条（默认 6）
- 动画可整体关闭（仅文字提示）

### 4.5 设置界面

一个独立设置窗口，分区：

| 分区 | 内容 |
|---|---|
| 文字模型 | 接口地址 / API Key / 模型名（默认 DeepSeek：`https://api.deepseek.com` + `deepseek-chat`）+「测试连接」 |
| 视觉模型 | 启用开关 / 接口地址 / API Key / 模型名 / 截图间隔 +「测试连接」 |
| 监控 | 盘符勾选、噪音过滤规则编辑、隐私遮罩绘制（画框涂黑） |
| 弹幕 | 速度、密度、风格池编辑、动画开关、**本地模式开关** |
| 系统 | 开机自启、托盘常驻 |

**测试连接按钮**：
- 文字模型：发最小请求（让模型回一个字），成功显示 ✓ 及模型响应；失败显示具体原因（401 鉴权失败 / 404 模型名不存在 / 超时 / 网络不通）
- 视觉模型：除连通性外，发内置测试图（红色方块）问"这是什么颜色"，答对才提示"视觉能力正常"——验证真的"看得见"

### 4.6 配置与安全

- 配置存 `app.getPath('userData')/config.json`
- API Key 用 Electron `safeStorage` 系统级加密存储
- Key 只发送给用户自己填写的接口地址，绝不上传任何第三方

### 4.7 托盘

系统托盘图标，菜单：暂停/继续弹幕、暂停/恢复屏幕识别、打开设置、退出。

### 4.8 开机自启

`app.setLoginItemSettings` 实现，设置界面开关。

## 5. 错误处理原则：出错即提示，不降级

**总原则：任何错误都必须让用户看得见，绝不静默降级。** 错误发生时弹幕停止生成，直到问题解决。

**错误提示渠道**（错误触发时同时走以下渠道）：
- 系统通知（Electron Notification）："弹幕已暂停：API 调用失败（401 鉴权失败）"
- 设置窗口状态条：常驻显示当前状态与最近一次错误（绿色正常 / 红色错误）
- 本地日志（userData/logs/）：完整错误栈，便于排查
- 同一种错误节流通知：连续同类错误不重复轰炸通知，状态条与日志持续记录

**错误分类与行为**：

| 错误 | 行为 |
|---|---|
| 文字 API 失败（401 鉴权 / 402 余额 / 404 模型名 / 429 限流 / 超时 / 网络） | 停止文字弹幕，提示用户 |
| 视觉 API 失败 | 停止屏幕弹幕，提示用户；文件弹幕不受影响 |
| 未配置 API Key | 首次启动提示"未配置 API Key，打开设置填写"，弹幕暂停；用户可手动开启本地模式 |
| 截图失败 | 跳过本帧并提示一次（节流） |
| 监控句柄失效 | 自动重新挂载（内部自愈，不视为降级），并通知用户一次 |
| 断网 | 提示"网络不可用"，弹幕暂停；网络恢复后自动恢复弹幕并通知"已恢复" |

**恢复策略**：出错后每 60 秒自动重试一次；配置在设置中被修改/保存后立即重试；恢复成功即通知用户"弹幕已恢复"。

## 6. 测试策略

- **单元测试**（node:test）：降噪规则、攒批、限速、模板抽取、事件描述格式化
- **Demo 模式**：内置假事件生成器（模拟新建文件夹/删除/屏幕变化），不操作电脑也能看弹幕效果；也用于手动验收
- **手动测试清单**：配置测试连接、错误提示（故意填错 key 验证 401 提示与弹幕暂停）、恢复重试、多屏热插拔、暂停/恢复、开机自启、断网提示、托盘退出

## 7. 实施里程碑

- **M1 骨架**：Electron 工程、托盘、配置读写（safeStorage）、设置窗口框架
- **M2 核心闭环**：FileWatcher + 降噪 + 本地模式（手动）+ 演出层 → "文件操作 → 本地模式弹幕"跑通
- **M3 文字 AI**：DeepSeek 接入、攒批、限速、测试连接、风格池
- **M4 屏幕识别**：截屏 + 像素差异 + 视觉模型 + 隐私遮罩 + 托盘暂停
- **M5 完善**：Demo 模式、单元测试、手动验收、打磨动画

## 8. 非目标（v1 不做）

- 音效 / 真人语音
- 弹幕发送到真实直播平台
- Linux / macOS 支持
- 鼠标键盘等输入级 hook（UI 操作仅通过屏幕识别间接捕捉）
- 多用户 / 云同步配置
