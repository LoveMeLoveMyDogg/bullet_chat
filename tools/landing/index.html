🪟 Windows 安装
1. 点击上方「下载 Windows」按钮获取安装包
2. 双击 .exe，出现「未知发布者」提示时点 更多信息 → 仍要运行
3. 按向导安装（可自选安装目录），完成后从托盘打开设置，填入模型接口即可
🍎 macOS 安装
1. 点击上方「下载 macOS」按钮获取 .dmg，双击挂载
2. 将应用拖入「应用程序」，首次打开需 右键 → 打开（绕过 Gatekeeper）
3. 首次启用屏幕识别时，在 系统设置 → 隐私与安全性 → 屏幕录制 中授权（权限按应用独立，重装后需重新授权）
