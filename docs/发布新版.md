# 发布新版（检查更新）

应用内「检查更新」读取 `https://updates.zhipengcoding.com/version.json`（阿里云服务器 Nginx 静态站点，复用泛域名证书）。

## 分工原则

- **Windows 只负责打包**（产出 exe）
- **Mac 是统一发布入口**：SSH 凭据只放在 Mac，所有上传都在 Mac 上执行；发布脚本与平台无关，Mac 上可直接发布任意平台的包

## 发布步骤

1. **升级版本号**：`npm version patch`（或手改 package.json），并提交同步到两端（`git commit` + push / pull）。
   ⚠️ 发布前 **Mac 与 Windows 的 package.json 版本必须一致**——exe/dmg 文件名带版本号，脚本按本地 package.json 找产物。
2. **构建**：
   - Windows：`npm run build:win` → 产出 `dist/BulletChat-<版本>-win-x64.exe`
   - macOS：`npm run build:mac`（Intel 包加 `--x64`）→ 产出 `dist/BulletChat-<版本>-mac-arm64.dmg` / `...-mac-x64.dmg`
3. **Windows 打好的 exe 传到 Mac**，放进项目 `dist/` 目录（微信/网盘/共享盘均可）。
4. **首次使用先配置 deploy.env**：复制 `deploy.env.example` 为 `deploy.env` 并填写 SSH 参数（只需在 Mac 上配，`deploy.env` 不入库）：
   - `DEPLOY_HOST`：更新服务器 IP 或域名
   - `DEPLOY_USER`：SSH 登录用户（如 root）
   - `DEPLOY_SSH_KEY`：SSH 私钥文件路径（macOS 示例 `/Users/你的用户名/.ssh/your-ssh-key.pem`）
   - `DEPLOY_PATH`：服务器上更新站点的静态根目录
5. **发布**：
   ```bash
   node tools/publish-update.js --platform win-x64 --notes "更新说明"
   # mac 用 mac-arm64 / mac-x64
   ```

## 脚本行为（tools/publish-update.js）

- **只更新当前平台条目、保留另一平台条目**——拉取远程 version.json 失败会中止上传，防止误删另一平台
- 自动计算 SHA256，上传安装包 + version.json，并修正属主

## 发布后验证

1. 浏览器访问 `https://updates.zhipengcoding.com/version.json`，确认对应平台条目的版本号与 sha256 已更新、另一平台条目仍在
2. 应用内「检查更新」→ 应提示新版本 → 下载完整安装包 → 手动安装覆盖旧版

## 回滚

将服务器 `version.json` 中对应平台条目改回旧版本（并保留旧安装包文件），应用端即不再提示更新。
